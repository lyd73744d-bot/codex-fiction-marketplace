# 写小说真的太简单了 - 交付说明

版本 4.8。插件由精简后的写作 Skills、本地核心服务、项目模板和按次确认、可核对余额的模型网关组成。

本版修复中文任务名被直接写入 HTTP 请求头、继而误报“网关离线”的问题。中文任务名现在会转换成稳定的 ASCII 标识；真正的连接失败也不再提示用户重启服务器。自动健康探针与公开 `/healthz` 同步停用，连接状态只依据真实账号、目录和生成请求。

## 产品规则

- 首次激活初始化会在默认浏览器打开绑定页，即使本机已有登录会话也会展示一次；作者先登录或注册，绑定成功后才能调用外部模型。
- Codex 固定在总责编位；正文初稿、改写、润色和去 AI 味默认由作者当次同意的外部写作模型完成。
- 不注册也能完成引导、脑洞、研究、工程、台账、伏笔、必要的章节笔记和审稿；作者也可使用自己已有的其他写作模型。
- 每次调用其他模型前都推荐并展示模型费率、预计积分和当前余额，再询问“是否使用这个模型”；选择使用才调用。调用后再次读取余额，有限套餐核对实际扣费，无限/托管套餐明确标记为不扣有限积分。绑定状态可以保存，但以后每次调用仍需询问。
- 绑定后可直接点名实时目录中的 DeepSeek V4 Flash / DeepSeek V4 Pro 或其他模型；插件负责把自然语言选择转换为模型 ID，并继续执行费率展示与本次确认。
- 参考样书、完整片段摘取、剧情/对话/文风对比、人物/设定/时间线/伏笔台账全部保留。
- 样书观察默认只保存在样书目录，作者确认前不进入本书 Skill，也不整份发送给正文模型。
- 正文初稿、重写、润色和去 AI 味默认直接写入 `正文/第XXX章_标题.txt`；同一章重新生成会覆盖同一路径，避免堆大量临时稿。
- 每次外部模型输出都会在 `审稿记录/模型写作记录.md` 留索引；作者确认采用后再结算当前进度和事实台账。

## 新手主线

新书/文件夹 -> Codex 自动建项目台账 -> 问清原始脑洞 -> 可选外部模型发散/优化 -> 作者定方向 -> 参考样书学习 -> 文风对比 -> 宽松大纲 -> 事实核验与人物卡 -> 可选章节笔记 -> 外部模型直写正文 -> Codex 检查 -> 不满意则重新生成覆盖 -> 作者确认采用 -> 更新台账。

## MCP 边界

MCP 共 25 个工具。16 个负责网关连接、账号状态、模型目录、模型调用、正文落盘和网关自检；5 个本地核心工具负责项目建档、样书导入与学习、研究文档、人物卡、事实库和文风锚点；另有 3 个公开榜单工具和 1 个授权下载工具。Codex 负责写作指导、必要的章节笔记、正文检查和协调，不默认抢正文 A 位。

样书学习只从作者有权使用的文本中截取少量完整片段，保留文件名和行号，用于本地对照。它学习剧情因果、人物对话和叙述文风，不把样书变成固定模板，不复制原书专名、设定、完整桥段或标志性表达。

用户侧只需要账号页：注册、登录、连接状态、积分余额、兑换码和购买入口。管理页仅供管理员使用。

## 安装与验证

```bat
node scripts\register-personal-marketplace.js
npm test
```

安装目录：`%USERPROFILE%\plugins\longform-fiction-director`

实网多模型测试是可选操作，需要时再手动登录：

```bat
node scripts\open-login-now.js
node scripts\smoke-live-gateway.js
node scripts\stress-live-gateway.js
```
