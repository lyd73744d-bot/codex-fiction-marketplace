# 写小说真的太简单了 - 交付说明

版本 4.2.5。插件由精简后的写作 Skills、本地核心服务、项目模板和按次确认的模型网关组成。

## 产品规则

- 安装后不弹登录页，不强制注册。
- Codex 固定在总责编位；正文初稿、改写、润色和去 AI 味默认由作者当次同意的外部写作模型完成。
- 不注册也能完成引导、脑洞、研究、工程、台账、伏笔、必要的章节笔记和审稿；作者也可使用自己已有的其他写作模型。
- 每次调用其他模型前都推荐并询问“是否使用这个模型”，不展示积分；选择使用才调用。首次使用永久保存网关绑定，但以后每次调用仍需询问。
- 参考样书、完整片段摘取、剧情/对话/文风对比、人物/设定/时间线/伏笔台账全部保留。
- 样书观察默认只保存在样书目录，作者确认前不进入本书 Skill，也不整份发送给正文模型。
- 候选稿先保存；作者确认前不写入正式正文、不结算台账。
- 每次外部模型输出同时保留候选 txt、纯文本副本和 `审稿记录/模型写作记录.md` 索引，方便跨任务恢复写作过程。

## 新手主线

新书/文件夹 -> Codex 自动建项目台账 -> 问清原始脑洞 -> 可选外部模型发散/优化 -> 作者定方向 -> 参考样书学习 -> 文风对比 -> 宽松大纲 -> 事实核验与人物卡 -> 可选章节笔记 -> 外部模型写候选稿 -> Codex 验收 -> 作者确认 -> 正文与台账。

## MCP 边界

MCP 共 25 个工具。16 个负责网关连接、账号状态、模型目录、模型调用、候选文件和网关自检；5 个本地核心工具负责项目建档、样书导入与学习、研究文档、人物卡、事实库和文风锚点；另有 3 个公开榜单工具和 1 个授权下载工具。Codex 负责写作指导、必要的章节笔记、候选验收和协调，不默认抢正文 A 位。

样书学习只从作者有权使用的文本中截取少量完整片段，保留文件名和行号，用于本地对照。它学习剧情因果、人物对话和叙述文风，不把样书变成固定模板，不复制原书专名、设定、完整桥段或标志性表达。

用户侧只需要账号页：注册、登录、连接状态、积分余额、兑换码和购买入口。管理页仅供管理员使用。

## 安装与验证

```bat
node scripts\register-personal-marketplace.js
npm test
```

安装目录：`%USERPROFILE%\plugins\longform-fiction-director`

实网多模型测试是可选操作，需要时再手动登录：

```bat
node scripts\open-login-now.js
node scripts\smoke-live-gateway.js
node scripts\stress-live-gateway.js
```
