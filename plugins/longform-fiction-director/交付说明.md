# 写小说真的太简单了 · 融合版交付说明（4.1.0-fusion.26）

## 这是什么
辅助型中文长篇写作 Codex 插件（责编引导，不是一键工厂）。
含：Skill + MCP + 本地台账 + 流式多模型写候选 txt。

## 安装
1. 运行 `点我安装.cmd`
2. 首次安装会强制弹出网关登录窗（含积分小店）
3. 在 Codex 启用插件 `longform-fiction-director`

## 登录弹窗规则
1. **首次安装/从未登录**：必须弹一次
2. **弹过后/登录成功后**：不随便再弹
3. **只有掉线**：才自动再提醒
4. 手动再开：`node scripts/open-login-now.js` 或 `fiction_open_gateway_login`
5. 查看当前可用登录页：`node scripts/print-login-url.js`

当前机器若已开登录保活，也可直接打开：
- 登录页见 `%LOCALAPPDATA%\Zizhuji\longform-fiction-director\login-url.txt`
- 小店：https://catfk.com/shop/ZVZNANU8

## 写作主线（责编引导）
脑洞 → 样书导入学习 → 文风锚点 → 大纲（黄金三章骨架） → **联网核验/事实库/人物卡** → 细纲控制卡 → 初稿候选 txt → 文风对比/多模型去AI味 → 作者确认后入台账

### 历史/真实题材硬门槛
出现明朝/卢象升/官职等信号时：未完成联网回填+事实库+人物卡，禁止生成正文候选。

### 连续生成（隐藏）
黄金三章就绪后，仅当作者明确说“可以连续/授权连续…”才开启；默认不推销。

## 多模型与 txt
- 流式优先 → 失败重试 → 非流式兜底 → 多模型回退链
- 完整落盘：`项目/Codex候选/*.txt`
- 纯正文：同名 `.body.txt`（可再喂模型）
- 选型：`fiction_recommend_models`（mode=quick|deep）
- 生成：`fiction_generate_to_file`
- 优化：`fiction_optimize_with_models`
- 不登录也能本地候选，但强模型效果会差很多

## 去AI味方法 skills
humanizer-zh / humanizer-methods / deslop-dialogue|narration|pacing|emotion|info-dump|hook|explain / style-compare / anti-ooc-research
