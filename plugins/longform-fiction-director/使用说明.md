# 写小说真的太简单了 - 使用说明

这是给新手用的中文长篇写作责编插件。Codex 固定负责引导、脑洞、研究、工程、必要的章节笔记和验收；正文初稿、改写与去 AI 味默认交给作者当次同意的外部写作模型。插件首次激活会把绑定页打开到默认浏览器，完成登录/注册后才能调用外部模型；绑定后可以直接说“用 DeepSeek V4 Pro”，不需要记工具名。本地项目和责编工作仍可继续。

## 最简单的开始方式

对 Codex 说下面任意一句即可：

- “我要开一本新书。”
- “读取这个小说文件夹，帮我建立台账。”
- “读取参考样书，学习手法并和本章对比。”
- “接着写下一章，直接写到正文。”

Codex 会一次只推进一个清楚步骤，并在资料缺失、人物设定冲突或流程走偏时提醒。

选择“新书”后先聊类型和最想写的点，不要求先取书名。方向基本清楚后，Codex 会自动给一个可随时修改的临时项目名，再询问保存目录并建好台账。

## 默认写作流程

1. 新书先问类型和核心吸引力；已有小说先读取文件夹
2. Codex 自动生成可修改的临时项目名，再建立 `辅助文档/00-08`、`细纲/`、`正文/`、`样书/` 和 `审稿记录/模型写作记录.md`
3. Codex 问清原始脑洞，收束前可选用一个外部模型发散/优化，再由作者定方向
4. 导入参考样书，按剧情、对话和文风保存带出处的完整小说片段
5. 把当前稿与样书并排看，有用的写法才试，不照抄也不自动变成限制
6. 建大纲、人物台账、世界观、时间线、伏笔和防 OOC 事实库
7. 内容容易接错时 Codex 留一页内章节笔记，外部写作模型直接写入 `正文/第XXX章_标题.txt`
8. 不满意就重新生成或优化覆盖同一章；作者确认采用后再更新台账

## 模型与网关

- **默认路径**：Codex 先完成不需要网关的责编工作；到正文阶段再推荐一个外部写作模型。
- **先绑定**：首次打开先完成登录/注册，绑定页会展示账号状态、模型费率和积分入口。
- **每次询问**：准备调用其他模型前，插件推荐一个模型并说明用途，展示本次预计积分和调用前余额，然后问“是否使用这个模型？”。
- 当次选择“使用”：才调用本次模型；调用结束后再次读取余额并报告是否实际扣费。无限/托管套餐会明确标记为不扣有限积分。
- 当次选择“不使用”：不弹网关，也不让 Codex 自动接管整章；继续把这一章想清楚。
- 永久绑定只免除重复绑定账号，不会取消以后每次调用前的询问。
- 直接指定模型：绑定后可以说“用 DeepSeek V4 Flash 快速处理”或“用 DeepSeek V4 Pro 复核这一章”；插件仍会先展示实时费率和余额，得到本次确认后才调用。
- 登录凭据、API 密钥和兑换码不要发到对话里，只在网页中输入。
- 正文生成和改写默认直接写入 `正文/`，同一章重新生成会覆盖同一个文件。`审稿记录/模型写作记录.md` 会留下索引，方便恢复协作历史。

## 参考样书

把有权使用的样书放进项目 `样书/书名/`，或用 `fiction_sample_book` 导入。学习后会保留两份本地材料：

- `00_手法学习笔记.md`：记录有原文依据、但尚未自动采用的观察。
- `01_剧情对话文风摘句.md`：按剧情、对话、文风保存少量完整小说片段，并标明文件名和行号。剧情与对话保留连续几段，文风保留完整长句或一小段，不用碎短句凑数。

这些片段是本地参考，不是仿写命令。`fiction_compare_style` 会把它们与当前稿并排看：剧情看因果衔接，对话看人物目的、回避和停顿，文风看措辞、句段节奏、叙述距离和说透程度。觉得有用才试，不复制原书剧情、标志性措辞、句式、人物或设定，也不会自动写进本书 Skill。

## 本地核心工具

- `fiction_project`：建立或查看轻量写作项目结构
- `fiction_sample_book`：导入、列出、学习样书，或建立本书写作 Skill
- `fiction_research`：建立研究计划、资料文档和人物卡
- `fiction_facts`：建立、读取和更新事实与防 OOC 台账
- `fiction_voice_anchor`：保存本书叙述、对白、节奏和禁用腔调

## 网关工具

- `fiction_ensure_gateway`：检查状态并记录绑定；首次初始化会打开绑定页
- `fiction_open_gateway_login`：打开登录/注册/余额/兑换页
- `fiction_list_models` / `fiction_recommend_models`：读取实时模型费率，为本次调用推荐模型
- `fiction_generate_to_file`：调用网关模型生成正文；带章节号时默认写入 `正文/` 并覆盖同章，长文可用 `background: true`
- `fiction_generation_status`：读取后台生成状态和最终正文路径，等待时由 Codex 做本地连续性准备
- `fiction_write_local_candidate`：兼容工具；普通流程不用，只有明确要求临时稿时才保存
- `fiction_compare_style`：参考样书与本书文风对比
- `fiction_optimize_with_models`：按次确认的改写、润色或去 AI 味；默认用一个主模型覆盖同章正文

插件当前共提供 20 个 MCP 工具：15 个网关/正文生成工具，5 个本地核心工具。本地核心工具不注册也能使用；调用外部模型仍须作者每次确认。
