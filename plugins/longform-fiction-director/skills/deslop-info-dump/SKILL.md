# 去AI味：信息倾倒

> 主流程分工：Codex 诊断并验收，外部写作模型默认改正文；作者明确要求 Codex 写临时候选时才本地改。

## 铁律（先于下面所有改法）
- 换皮不算改：同义替换（倒吸凉气→吸凉气、下一秒→紧接着）仍是 AI 味。
- 只删表现手段，保留可核对事实（数字 / 物件 / 因果 / 伏笔 / 人物选择）。
- 删套话后补回现场功能，不补造五感、动作、比喻、天气、心理。综合改味见 `humanizer-zh`。

## 检查
- 大段世界观/规则说明
- 对话里互相上课
- 一上场就交代人物全部履历

## 改
1. 只留本章立刻推动冲突的信息
2. 其余改成争执中的碎片透露
3. 设定细节进台账/核验文档，不塞正文
4. 真实历史内容先走联网核验

## 输出
瘦身后的候选正文 txt。
