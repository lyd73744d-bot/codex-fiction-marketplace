# 去AI味：对话

> 主流程分工：Codex 诊断并验收，外部写作模型默认改正文；作者明确要求 Codex 写临时候选时才本地改。

## 铁律（先于下面所有改法）
- 换皮不算改：同义替换（倒吸凉气→吸凉气、下一秒→紧接着）仍是 AI 味。
- 只删表现手段，保留可核对事实（数字 / 物件 / 因果 / 伏笔 / 人物选择）。
- 删套话后补回现场功能，不补造五感、动作、比喻、天气、心理。综合改味见 `humanizer-zh`。

## 何时用
- 角色轮流演讲、互相科普
- 人人说话都像同一张嘴
- 对白在解释剧情，而不是争取、回避、试探或改变决定
- 角色把自己的动机、情绪、关系结论和“正确理解”一次说完

## 先读
1. 人物卡：这个人会不会这么说
2. 本章细纲：这句对白服务什么冲突
3. 样书手法笔记：对话密度与打断习惯

## 改法
1. 删开场寒暄和“如你所知”
2. 一句只干一件事：逼问 / 否认 / 交易 / 嘲讽 / 示弱
3. 人物只说此刻愿意说、敢说和说得出口的部分；按人物与场景允许回避、半答、答非所问、被打断或临时改口
4. 信息差不要靠角色当旁白补课
5. 保留口头禅与身份差，但不要标签化
6. 删掉读者能从动作、反应、上下文或后果推出的潜台词；必要事实与因果仍要让读者看懂

## 禁止
- 改剧情因果
- 让配角突然变智囊解说员
- 用“他严肃地说”堆情绪标签
- 用密集省略号、神秘碎句或人人欲言又止假装留白
- 对白刚停，旁白马上解释“他其实是……”或“这意味着……”

## 输出
完整对话修订后的候选正文 → 写入 `Codex候选/*.txt`（含 .body 纯文本）。作者确认前不覆盖正式正文。
