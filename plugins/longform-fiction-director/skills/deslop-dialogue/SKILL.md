# 去AI味：对话

## 何时用
- 角色轮流演讲、互相科普
- 人人说话都像同一张嘴
- 对白在解释剧情，而不是施压/躲闪/试探

## 先读
1. 人物卡：这个人会不会这么说
2. 本章细纲：这句对白服务什么冲突
3. 样书手法笔记：对话密度与打断习惯

## 改法
1. 删开场寒暄和“如你所知”
2. 一句只干一件事：逼问 / 否认 / 交易 / 嘲讽 / 示弱
3. 用打断、停顿、答非所问制造摩擦
4. 信息差不要靠角色当旁白补课
5. 保留口头禅与身份差，但不要标签化

## 禁止
- 改剧情因果
- 让配角突然变智囊解说员
- 用“他严肃地说”堆情绪标签

## 输出
完整对话修订后的候选正文 → 写入 `Codex候选/*.txt`（含 .body 纯文本）。作者确认前不覆盖正式正文。
