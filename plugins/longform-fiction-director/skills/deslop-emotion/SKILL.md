# 去AI味：情绪

## 禁
- “他很愤怒/她很悲伤”直接贴标签
- 大段心中暗想解释自己为什么难过
- 全员同一套煽情句式

## 做
1. 情绪改成身体反应、停顿、失态动作
2. 让对话先硬、后软，或先躲后爆
3. 对照人物卡：此人会不会当众崩溃
4. 只保留会改变下一步选择的念头

## 输出
候选 txt；剧情因果不动。
