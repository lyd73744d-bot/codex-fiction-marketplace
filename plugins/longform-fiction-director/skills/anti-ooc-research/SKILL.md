# 防 OOC / 联网核验

## 硬规则
真实人物、历史制度、地理器物或专业流程会影响当前剧情时，先确认需要核实的问题，再真实检索、回填来源和边界，然后进入正文。与当前段落无关的资料不提前堆满。

## 流程
1. Codex 先说明当前故事里哪一处可能写错，并据此列检索词
2. 用内置浏览器按检索词打开可信来源
3. 回填：Codex 把来源/事实/禁写写进 `辅助文档/08_事实库_防OOC.md`
4. 真实人物：Codex 更新 `辅助文档/02_人物台账.md`（标注 historical，附来源）
5. Codex 自查：联网回填 + 事实库 + 人物卡是否齐了，齐了才写正文
6. 章后：Codex 更新时间线/伏笔台账，并对照前文做连续性自检

## 禁止
- 空核验文档开写
- 用模型记忆冒充检索
- 把不确定内容写成铁事实

## 作者沟通
- 作者已经说明史实边界时直接执行，不重复询问。
- 只有虚构边界会改变剧情时，才问一个问题。
- 检索词按当前问题决定，不固定数量，不把搜索任务甩给作者。


## 强制联网核验（责编必做）

1. 大纲或章节涉及会影响因果的真实内容时，先做联网搜索，再更新有关台账并写正文。
2. 真实历史人物：搜生卒、官职、关键事迹、常见误读；写入事实库与人物卡，并标注来源。
3. 虚构人物：明确“虚构边界”，禁止借用真实史实张冠李戴。
4. 真实人物出场前补足当前场景需要的身份、立场与史实边界；虚构人物不为填表强制建完整卡。
5. 顺序建议：
   - Codex 先出检索计划（检索词 + 风险点）
   - Codex 内置浏览器真实搜索
   - Codex 回填事实库 md
   - 人物台账落盘后再进入细纲/正文
6. 任何不确定的专名、地名、官制、器物，宁可先搜再写，也不要硬编。


## 历史/真实题材硬门槛

当脑洞或大纲出现历史/真实人物信号时，Codex 把联网回填 + 事实库 + 人物卡当作**硬前置**：未完成前禁止生成正文。
