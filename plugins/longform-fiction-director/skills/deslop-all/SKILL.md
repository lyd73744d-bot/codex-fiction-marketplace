# 去AI味：综合诊断与修改

> 主流程分工：Codex 诊断并验收，外部写作模型默认改正文；作者明确要求 Codex 写临时稿时才本地另存。综合深度改味见 `humanizer-zh`。

## 铁律（所有分类共用，优先于下面一切规则）

- **换皮不算改**：同义替换（倒吸凉气→吸凉气、下一秒→紧接着、这意味着→也就是说）仍是 AI 味。
- **只删表现手段，保留可核对事实**：数字、物件、因果、伏笔、人物选择不得删。
- **删套话后补回现场功能**，不补造五感、动作、比喻、天气、心理。
- **改味不改剧情**：因果顺序、伏笔埋点、人物决定不动。
- 有章节号时，改稿直接覆盖同章 `正文/` 文件；只有作者明确要求多个版本时才另存临时稿。

---

## 一、对话

### 何时用
- 角色轮流演讲、互相科普
- 人人说话都像同一张嘴
- 对白在解释剧情，而不是争取、回避、试探或改变决定
- 角色把自己的动机、情绪、关系结论和"正确理解"一次说完

### 改法
1. 删开场寒暄和"如你所知"
2. 让每轮对话有当前人物自己的目的；一句话可以同时试探、遮掩和改变关系，不拆成机械功能句
3. 人物按身份、关系和现场决定说多少；允许直说，也允许回避、半答、答非所问、被打断或临时改口
4. 信息差不要靠角色当旁白补课
5. 保留口头禅与身份差，但不要标签化
6. 删掉读者能从动作、反应、上下文或后果推出的潜台词；必要事实与因果仍要让读者看懂

### 禁止
- 让配角突然变智囊解说员
- 用"他严肃地说"堆情绪标签
- 用密集省略号、神秘碎句假装留白
- 对白刚停，旁白马上解释"他其实是……"或"这意味着……"

## 二、叙述

### 症状
- "总而言之 / 不难看出 / 这意味着"
- 空泛排比、正确但无画面
- 翻译腔：过长定语、英文思维句式
- 先总结情绪，再补动作
- 同义反复（他非常生气，他怒了）
- 动作或对白刚结束，旁白立刻翻译潜台词、动机和关系结论
- 细纲验收流程腔：正文按任务栏目逐项展示设定，主角持续给出最优处理

### 改法
1. 先删总结句，只留事件与反应
2. 抽象判断落到原文已有的动作/物件/感官；原文没有就直接删判断，不凭空补五感
3. 段落可以推进，也可以停留、观察或承接余波
4. 背景在人物当前判断或行动真正需要时出现，本章用不到的可以不写
5. 极端词（非常/极大/无比）能删就删
6. 现场已经能证明的情绪和意图不再讲解；让动作、反应、上下文或后果承担答案

### 自检
- 删掉形容词后，因果还在吗？
- 读者是看见了，还是被通知了？
- 有没有连续三句同一句式？
- 抹掉专名后，整章是不是仍像同一份功能验收流程？

---

## 三、情绪

### 典型问题
- "他很愤怒/她很悲伤"直接贴标签
- 大段心中暗想解释自己为什么难过
- 把情绪标签一律换成"眼神一沉/心头一震/拳头缓缓握紧"——那是换了一套模板，不是去味

### 改法
1. 情绪先落到人物在乎的对象、关系和选择；原文已有有用动作或后果时可以沿用
2. 直说情绪本身没有错；原文没有可用动作时直接说清，**不补造身体反应**
3. 情绪已写清后，不再补"心里乱得说不清是什么滋味"这类同义重复
4. 让对话先硬后软、或先躲后爆，用现场关系承载情绪
5. 对照人物卡：此人会不会当众失态
6. 只保留会改变下一步选择的念头

## 四、节奏

### 两类病
1. **太赶**：转场连跳，结果还没来得及被人物承受
2. **太水**：同一信息和情绪反复解释，读者没有得到新的理解

### 改法
1. 标出本章正在处理的主要事情，不强求唯一冲突
2. 保住动作、位置、信息和情绪的连续性
3. 只压缩重复解释；段落可以同时承担动作、观察和关系变化
4. 收尾可以完成一件事，也可以停在余波、未完成动作或关系变化上，不强制悬念
5. 中间允许观察、犹豫、日常动作、关系余波和没有新事件的停留

---

## 五、章尾钩

章节不一定需要钩子。自然收尾可以是具体结果、动作完成后的余波、关系变化，或确实存在的未完成行动。

### 失效收尾
- 无来由惊吓
- 用一句可移植到任何故事的预告宣布后续更大
- 与本章因果无关的异常闯入
- 只换近义词的通用悬念口号

### 自然收尾
- 由本章已经发生的事自然停住
- 人物选择产生了具体结果
- 最后一个动作、物件或对白仍属于这个场景

### 流程
1. 确认本章主冲突是否兑现
2. 判断原文需要完成、停留还是保留未完成行动
3. 只改确有问题的尾段

---

## 六、信息倾倒

### 检查
- 大段世界观/规则说明
- 对话里互相上课
- 一上场就交代人物全部履历

### 改法
1. 只留本章当前判断、关系、行动或读者理解真正需要的信息
2. 其余改成争执中的碎片透露
3. 设定细节进台账/核验文档，不塞正文
4. 真实历史内容先走联网核验

---

## 七、解释腔 / 总结腔

### 典型句
- 这意味着……
- 不难看出……
- 他明白了一个道理……
- 从这一刻起，一切都不一样了

### 改法
1. 删掉结论句，改写为具体选择或损失
2. 角色不要替读者总结主题
3. 需要信息时，用行动失败/对话试探带出
4. 主题让读者自己品，不写进旁白讲义
5. 对白和动作已经显出的动机、情绪与关系变化不再紧跟一句标准答案

不得把留白做成谜语：不堆省略号，不故意删掉理解剧情必需的信息，也不让所有人机械地欲言又止。

## 使用方式

调用时直接说明要修哪个维度，或全部扫描：
- `修对话` → 进入第一节
- `修叙述` → 进入第二节
- `修情绪` → 进入第三节
- `修节奏` → 进入第四节
- `修章尾` → 进入第五节
- `修信息堆砌` → 进入第六节
- `修解释腔` → 进入第七节
- `全部扫` → 先通读整章，只报真实存在的问题，不强求覆盖所有维度

深度综合检查走 `humanizer-zh`。无论使用哪一个，实际改写仍按主 Skill 每次询问作者后交给外部写作模型；本 Skill 只负责诊断、约束和验收。

## 快速路由（遇到什么问题用哪一节）

| 症状 | 跳到 |
|---|---|
| 角色轮流演讲、互相科普、对白假 | 第一节：对话 |
| 叙述空泛、排比总结、翻译腔 | 第二节：叙述 |
| 情绪贴标签、拳头缓缓握紧 | 第三节：情绪 |
| 太赶或太水、节奏断 | 第四节：节奏 |
| 章尾廉价悬念、通用预告口号 | 第五节：章尾钩 |
| 大段世界观/设定倾倒、对话互相上课 | 第六节：信息倾倒 |
| "这意味着""不难看出"、总结腔 | 第七节：解释腔 |
| 多种症状混合 / 综合改味 | 直接用 `humanizer-zh` |

> 只有单一症状时用对应节；多种混合或整章改味走 `humanizer-zh`。
