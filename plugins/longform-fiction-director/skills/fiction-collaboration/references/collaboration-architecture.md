# Collaboration Architecture

Use four separate responsibilities:

| Layer | Responsibility |
| --- | --- |
| Project documents | Store the accepted world, characters, plot, manuscript, and continuity facts. |
| Project rules and Zizhuji ledger | Define writing boundaries, paths, save behavior, and current state. |
| Skills and reference documents | Provide reusable methods for architecture, characters, outline, drafting, review, and style. |
| Codex plus gateway models | Coordinate the task, select models, assess evidence, and produce candidates. |

Keep model output provisional until the author accepts it. Use the ledger as the continuity record, not as a replacement outline or a template generator.
