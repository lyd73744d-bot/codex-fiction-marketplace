# 章节控制卡（写前必填，短）

用途：细纲确认后、写候选正文前。控制卡不是 spoiler 摘要，是施工命令。

## 卡片模板（复制填写）

```md
# 第N章 控制卡

## 本章唯一任务
- 一句话：本章必须完成的情节功能

## 开场钩子（前 300 字）
- 钩子类型：冲突 / 悬念 / 反差 / 危机 / 信息差
- 具体动作：谁在做什么、压力从哪来

## 节拍（3–5 个）
1. 
2. 
3. 
4. （可选）
5. （可选）

## 人物
- 主角本章目标：
- 对手/阻力：
- 关系变化（若有）：

## 信息与伏笔
- 新抛出：
- 回收/推进：
- 禁止提前泄露：

## 中段回报
- 本章给读者的兑现（小胜/反转/真相碎片）：

## 章末钩子
- 钩子类型：
- 具体落点：
- 逼问下一章的问题：

## 禁止事项
- 不能写成流水账的点：
- 不能OOC：
- 不能解释腔说教：

## 预估篇幅
- 字数带：
```

## 使用规则
1. 细纲阶段结束时产出控制卡，给作者看
2. 作者确认或改卡后，才调用模型写候选正文
3. 写正文时控制卡优先于“自由发挥”
4. 质检时对照控制卡：任务是否完成、钩子是否落地
