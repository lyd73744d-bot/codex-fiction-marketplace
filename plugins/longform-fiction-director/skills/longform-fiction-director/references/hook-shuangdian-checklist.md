# 钩子 / 爽点 / 金手指 检查清单

用于细纲自检与终检。每项只打：有 / 弱 / 无 + 一句证据。

## A. 章首钩子（前 300–500 字）
- [ ] 有具体场面，不是背景介绍
- [ ] 有压力或信息差，不是日常起床
- [ ] 主角已进入行动或被迫反应
- [ ] 读者能产生“为什么/会怎样”的追问

## B. 爽点（本章至少一个清晰兑现）
- [ ] 爽点类型明确：打脸 / 逆转 / 升级 / 揭秘 / 守护 / 智胜 / 情绪释放
- [ ] 有铺垫（憋）→ 触发 → 释放，不是突然喊爽
- [ ] 代价或风险仍在，不是无脑开挂
- [ ] 爽完仍留钩子，不泄劲收工

## C. 金手指 / 核心外挂（若本书有）
- [ ] 规则边界清楚（能做什么/不能做什么）
- [ ] 本章使用符合已定规则，无临时加设定
- [ ] 展示优先于讲解
- [ ] 推动情节，不是说明书

## D. 节奏
- [ ] 中段有回报，不一路平推
- [ ] 对话推动关系/筹码，不是复读设定
- [ ] 章末钩子与开场压力形成闭环或升级

## 输出格式（质检用）

```md
### 网文专项
- 章首钩子：有/弱/无 — 证据：
- 爽点：有/弱/无 — 类型： — 证据：
- 金手指：有/弱/无/不适用 — 证据：
- 章末钩子：有/弱/无 — 证据：
- 建议（最多 3 条，只改表达或节拍，不改作者已定剧情）：
```
