# 什么时候用模型

## Codex 总责编默认完成
- 问清脑洞、拆卡点、解释进度
- 查资料与核验历史/职业事实
- 建项目、软台账、人物/时间线/伏笔，以及确有必要的一页内自然章节笔记
- 本地样书粗提、文风统计对比
- 读取当前正文并检查事实、因果、人物和题材承诺

## 外部写作模型默认占 A 位
- 脑洞末段的可选发散与优化：补变体、长期发动机和反常规解法，Codex 回收后去重并让作者选择
- 正文初稿（`fiction_generate_to_file`）
- 按已确认事实和作者指出的问题重写、对白/动作/情绪优化
- 去 AI 味、文气调整和润色（`fiction_optimize_with_models`）
- 作者同意时的难章复写或第二写手复核

作者拒绝本次外部模型时，不默认由 Codex 接管整章，也不新建临时稿；继续把这一章想清楚。只有作者明确命令 Codex 写临时稿时，才用本地写入工具。

大纲、细纲和章节笔记都受 `natural-writing-system.md` 约束：只记方向和硬事实，不得成为场景、字数、展示次数或章尾效果的执行表。

## 选型粗原则
- 探索/脑暴先由 Codex 问清核心；收束前默认建议一次可选快模型发散，作者当次同意才调用
- 正文：中强叙事模型
- 正文优化/难章重写：更强且擅长人物声音的模型
- 以 `fiction_recommend_models` + 实时目录为准

## 传输
单次流式提交 → 超时不重发 → 仅空流做一次非流式兼容 → 带章节号时完整写入 `正文/` 并覆盖同章
