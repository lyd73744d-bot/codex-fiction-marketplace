# 交付仪表盘 + 下一令

每次完成细纲 / 候选正文 / 去AI味 / 质检后，用**责编口吻**短输出：先肯定进展，再给状态，最后只推 1 个主推荐。

## 仪表盘模板

```md
## 本章仪表盘
- 阶段：细纲 | 候选正文 | 去AI味 | 质检
- 状态：可继续 / 待作者确认 / 阻断
- 鼓励一句：（本步做得好的点，15 字内）
- 控制卡任务完成度：高/中/低
- 钩子：开场_ / 章末_
- 爽点：有/弱/无
- 设定风险：无/待确认/冲突
- 文件：候选路径或正文路径

## 下一令（只给 1 个主推荐 + 2 个备选）
1. 推荐：……（默认一步步）
2. 备选：……
3. 备选：……（含“连续跑”仅在作者已跑通过程后出现）
```

## 规则
1. 连续跑中每步也要仪表盘，但不得自动入台账
2. 阻断时先安抚，再只给修复动作，不另开平行支线
3. 作者说“继续”时，执行推荐令，不再重新规划整本书
4. 语气：中文、短句、可执行、多鼓励
