# 新书模板

这是放在 `小说项目/` 里的可用母版。复制它、改成书名后，直接在副本里填写；不要在这一份母版里写某本书的具体内容。

开始时先填写 `辅助文档/00_使用说明与当前状态.md`。它不替代正文，台账只记录已经写进正文或由作者确认的事实。

## 平时怎么用

1. 开工时看 `辅助文档/00_使用说明与当前状态.md`、本章细纲，以及本章会碰到的人物、设定、时间线和伏笔。
2. 细纲只拆当前章。卡住时可以先写问题、条件和几个可选动作，不急着定成剧情。
3. 正文定稿后，回填真正发生的变化：人物状态、物件/资源、时间、伏笔和下一章承接。
4. 要润色或质检时，把候选稿放进 `Codex候选/`；每次外部模型输出会自动追加到 `审稿记录/模型写作记录.md`，没有开启质检也可以直接由作者决定是否采用。
5. 有参考样书时，放进 `样书/书名/`。Codex 先写 `00_手法学习笔记.md`，再用笔记对比候选稿；只学习手法，不复制原文。

## 文件边界

- `辅助文档/`：全书持续有效的事实和约定。
- `细纲/`：当前章的可执行安排和上一章交接。
- `正文/`：确认后的正式正文。
- `Codex候选/`：模型或 Codex 给出的未定稿候选，不能当作已发生事实。
- `审稿记录/`：去 AI 味、连续性和事实核对结果。
- `审稿记录/模型写作记录.md`：外部模型输出索引，只恢复写作过程，不承担故事事实记忆。
- `样书/`：作者有权使用的参考文本和手法学习笔记，不进入故事事实台账。

没有填的栏目可以删掉。不确定的内容写“待确认”，不要让模型自行补全后写进台账。
