# 当前章细纲

这里不用填表，也不用补齐栏目。需要时直接写几段连贯的普通话：上一章留下什么局面，本章事情怎样继续，人物作了什么选择，相关人物出于各自处境怎样回应，最后有什么真实改变，又有什么暂时没有说透。容易写错的史实、知情范围和物件状态，写到相关位置时顺手提醒。

卡住时只想当前这一处：人物为什么现在要动，他习惯怎样处理，别人各自想保住什么，这次选择会让谁改变做法。想清楚就继续讲故事，不把问题抄成待填项目。

重要章节可以写得较充分，过渡章节可以很短。不要固定场景数、段落字数和章尾形式，不要把内容排成“先做 A、再做 B、最后发现 C”的施工顺序。开头可以从本章任何真正有生命的位置进入，正文也可以重组信息披露。未确认的姓名、人数、日期、存量和结果写“待确认”或保留未知，不能补全。

正文确认后，再把真正发生的变化更新到对应台账；没有写进正文的细纲内容仍然只是想法。
