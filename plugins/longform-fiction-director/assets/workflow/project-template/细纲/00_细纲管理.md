# 细纲说明

细纲只是作者写给自己看的临时笔记，不是正文施工表，也不是每章必填文件。事情已经想清楚时，可以直接写正文。

需要细纲时，只在 `01_当前章细纲.md` 里用普通话记几段：上一章停在哪里，人物、关系或局势相对开头最值得发生什么变化，以及哪些已确认事实不能写错。没有必要的栏目就不写。方向不列“先做、再做、最后做”的动作顺序，具体经过留给正文。

不要制作表格，不分配段落字数，不编号安排固定场景，不规定前几百字必须出现什么，不预先设计读者依次提出的问题，也不要求每章都有反转、兑现或悬念。系统信息、人物反应和世界说明只在正文当下真正需要时出现。

细纲越写越长、开始替人物决定每一步时，立即删回一页以内。正文写完后，只把实际发生的事实更新到台账；没有写进正文的细纲内容仍然只是想法。
