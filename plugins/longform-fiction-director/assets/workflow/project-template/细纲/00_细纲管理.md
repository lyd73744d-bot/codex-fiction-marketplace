# 细纲管理

细纲是一张写前工作纸：用来接住上一章、明确这一章需要发生的变化，并把写后实际结果带回台账。它不是套公式，也不要求每章都具备同一种起伏或结尾。

## 文件

| 文件 | 用途 |
|---|---|
| `01_当前章细纲.md` | 当前要写的一章 |
| `02_写前卡_章节名.md` | 某章需要额外核对的材料、场景和事实 |
| `辅助文档/` | 长期事实、人物、设定、时间和伏笔 |

## 建一章细纲前

- 看上一章已经确认的结果，不从候选稿接剧情。
- 看本章会涉及的台账条目；信息不足时把问题写出来。
- 只确定本章真正需要处理的事。场景数量和安排随内容决定。

## 写完后

- 在本章细纲底部记下实际发生的结果和与原计划不同的部分。
- 先把事实回填台账，再建立下一章细纲。
- 未写进正文的候选想法保留在“待确认”，不要直接升级成设定。
