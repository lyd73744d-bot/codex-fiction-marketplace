# 当前写作状态

这份文件由 Codex 在工作中维护，不需要作者填表。它只记录这本书已经走到哪里、当前最值得处理什么，不规定以后必须按什么顺序创作。

## 这本书目前是什么

用几句自然话说明主类型、当前题材方向，以及读者持续追看主要在关心什么。方向变化时直接改写，不保留互相冲突的旧口号。

## 已经确定的内容

简要记录作者已经确认的核心想法、目前采用的大纲版本和正式正文进度。详细事实仍留在对应台账，不在这里复制。

## 眼前正在处理的事

说明当前卡在方向、大纲、资料、某一章、正文检查还是改稿，以及下一步最值得做的一件事。完成后更新成新的实际状态。

## 暂时没有决定的内容

只记确实影响近期写作的未知。没有影响的远期想法继续留白，不为显得完整提前填满。
