# 全书大纲

大纲首先要把这本小说从头到尾讲清楚。读完以后，应当知道主角从什么生活与关系中开始，为什么开始行动，哪些人物或势力真正影响他，中间经历哪些足以改变人物、关系或天下局势的大事，主要矛盾怎样转变，最后走到哪里。这不是简介，也不是只写主题和发展方向。

用自然段按故事阶段讲述。每一段至少说明这一阶段发生了什么，以及它为什么会把故事推入下一阶段。真正影响全书的选择、关系变化、敌我变化和阶段结局应当写出来；尚未决定的具体办法可以留白，并明确标为可能方向。

完整不等于写死。不要预设固定章数、分卷数量、黄金三章、每章兑现、升级节点和结尾悬念，也不要把事件拆成逐章任务。近期内容可以具体，远期内容可以保留分支，但不能只写“继续成长”“建立势力”“走向天下”这类没有事件与因果的空方向。

世界、时代、势力、主要人物和主要矛盾按这本书真正需要的程度说明，不必填齐固定栏目。人物、时间、物件、系统数值和史实边界分别留在对应台账里。大纲不复制这些表，也不把台账项目轮流变成剧情任务。

写完后只问两个问题：陌生人能不能复述这本书大致讲了什么；每个主要阶段是不是由上一阶段的结果自然逼出来。如果不能，大纲还没有完成。
