## 一、世界概况

### 基本背景

这是一个维多利亚工业革命风格与克苏鲁恐怖元素融合的世界。人类文明以帝国为核心，在诡异的威胁下艰难生存。世界的底层运行着人类尚未完全理解的超自然法则——诡异无处不在，古老的封印正在衰退，被遗忘的存在正在苏醒。

### 世界风貌

- **科技水平**：接近维多利亚时代。有左轮手枪、炼金火炮、蒸汽动力船舶、基础化学制药。没有电力，照明靠蜡烛和油灯
- **货币体系**：帝国通用货币（具体单位待确认）。守夜人内部有独立的积分制度
- **通讯方式**：通讯水晶（超凡道具，短距离）、信件、人力传递
- **照明与夜间**：城市夜间极暗，城墙符文微光和零星灯火是仅有光源。夜间是诡异活跃的高峰期
- **文字与语言**：帝国语为通用语言，存在古代文字（铭文、古铭文等）

## 三、超凡体系

### 超凡途径

人类可以通过踏上"超凡途径"获得超越常人的能力。不同途径有截然不同的力量来源和代价。

| 途径 | 力量来源 | 特征 |
|------|----------|------|
| **知识途径** | 知识本身 | 通过学习、研究、积累知识获得力量。含多个子方向（禁忌学、构造学等） |
| **异化途径** | 血肉变异 | 改造自身血肉获得战斗力 |
| **诡异途径** | 诡异力量 | 与诡异打交道、吸收诡异力量。风险极高 |
| **神选途径** | 神灵/天使 | 教会系统内的超凡途径 |
| **信徒途径** | 信仰 | 通过虔诚信仰获得力量 |
| **炉火途径** | 纯粹之炉 | 铁卫营的超凡途径。体表出现暗红纹路，可碳化诡异物质 |
| **机械途径** | 机械改造 | 飞升会途径。以机械替换血肉，除脑袋外全身可替换 |

### 超凡阶位

| 阶位 | 定位 | 帝国中的稀缺度 |
|------|------|------------|
| **一阶** | 入门超凡者 | 相对常见 |
| **二阶** | 正式超凡者 | 各组织主力 |
| **三阶** | 大师级 | 稀缺，各领域顶尖 |
| **四阶** | 帝国顶梁柱 | 极稀缺，总部直属级别 |

### 知识途径阶位（以禁忌学为例）

| 阶段 | 阶位 | 经验上限 |
|------|------|----------|
| 一阶 | 窥探者 | 10 |
| 一阶→二阶 | 寻觅者 | 20 |
| 二阶 | 求知者 | 100 |
| 三阶 | 博学者 | 未知 |

## 四、铭文学体系

### 概述

铭文学是一套独立于超凡途径的技艺体系，专注于在载体上篆刻特殊符文以实现各种效果。铭文学有自己的进阶体系，方向众多。

### 进阶机制

- 基础铭文学上限为10，突破后进阶到具体方向（上限提升至50）
- 进阶方向由**矮人**通过气息检测给出选项（石板形式）
- 可选方向数量取决于个体气息的复杂度
- 铭文学可以是主途径（纯铭文师），也可以是副途径（顺带学习）

### 铭文学方向

| 方向 | 说明 | 适用人群 |
|------|------|----------|
| **武器铭文学** | 将铭文篆刻在武器上，增强对诡异杀伤效果 | 战斗型超凡者。分水岭在四阶 |
| **大型铭文学** | 城墙阵法、城防封印、大型结构。深入后进入古大型铭文学领域 | 纯铭文师 |
| **古大型铭文学** | 大型铭文学的深层。最正统最难。**有知识诅咒**：锁死其他知识途径进展 | 仅适合纯铭文师 |
| **古铭文学** | 知识超凡专属。能在知识密度载体（精神核心、古代遗物的知识结构层）上篆刻。效果偏向封印、锚定、压制 | 知识超凡者。需绑定实物长期研究 |
| **诡异铭文学** | 借助诡异材料篆刻铭文，达到连锁效果。分支中的分支，不被主流看好 | 气息与诡异有亲和性者。不绑定地点 |

### 知识诅咒

古大型铭文学的特殊限制。学到一定程度后，所有知识途径的经验、感悟、积累会被强制导向铭文学本身。对纯铭文师无影响，但对有其他知识途径的超凡者是致命限制。

## 五、理智系统

### 基本规则

| 项目 | 说明 |
|------|------|
| **理智值** | 所有人都有理智上限，接触诡异/使用超凡能力会消耗理智 |
| **理智等级** | Ⅰ→Ⅱ→Ⅲ→Ⅳ，等级越高上限越高 |
| **理智屏障** | 额外防护层（满3层），需满理智状态才能缓慢修复 |
| **归零后果** | 精神崩溃/失控，极度危险 |

### 理智恢复途径

| 方式 | 效果 |
|------|------|
| 圣水 | 初/中/高级，直接恢复理智值 |
| 理智药剂 | 炼金产品，效果因品质而异。连续服用有递减 |
| 自然恢复 | 睡眠可缓慢恢复 |
| 被动技能 | 如"守御"系列，加速恢复速度 |

## 六、种族

### 人类

世界的主体种族。建立了帝国文明，发展出多种超凡途径和对抗诡异的组织体系。

### 矮人

| 项目 | 说明 |
|------|------|
| 外貌 | 矮小（约人类腰部高度），花白胡子，穿旧皮围裙挂满工具 |
| 可见性 | **常人不可见**，仅超凡者或特定条件下可察觉 |
| 专长 | 铭文学。矮人一族只走铭文途径 |
| 族群规模 | 极少，技艺传承是种族命脉 |
| 职能 | 当人类的铭文学达到进阶门槛时，矮人会主动上门引导方向选择 |
| 交易性 | 引导外族入门可获族内奖励。推荐方向大概率是自己的专精方向。会夸大其词诱导，但不会在选项本身造假 |

### 其他种族

目前仅发现矮人一族。是否存在更多种族尚不明确。

### 诡异的基本法则

## 九、知识之海

### 概述

知识之海是一个超维空间，存放和流转着世界上所有的知识。它不是人类创造的，而是一种自然存在的知识聚合体。

### 基本特征

| 项目 | 说明 |
|------|------|
| 进入方式 | 知识超凡者在特定条件下可打开"针孔"窥视 |
| 原生生物 | 知识之虫——以知识为食的生物，可与人类建立共生契约 |
| 知识之虫能力 | 吞噬知识→提纯→反哺宿主经验。可融合。嵌入眼睛后赋予增强视觉（气息可视化） |
| 危险性 | 知识之海中有更多未知原生物种。过度接触可能引起"那个声音"的降临 |
| 同源性 | 禁忌学知识本身是知识之海的一部分。知识之虫不吃禁忌学气息（同源自噬） |

## 十、关键世界法则

### 记忆抹除

- 某些不可名状存在具备**全世界范围的记忆抹除**能力
- 被抹除后：所有人无法记起相关事物，所有文档/档案中相关字段凭空消失
- 少数特殊被动技能可抵抗记忆抹除（极罕见）
- 被抹除者试图述说相关信息时，会被某种力量物理阻止（喉咙堵住、手势失效）

### 异梦

- 一种跨越现实与超自然空间的梦境感染
- 感染者每晚梦见特定场景（如黑色大海），逐渐被吞没
- 传染法则：不刻意接触源头几乎不会被传染，被传染者最多只能再传染一次
- 异梦的源头可能来自封印中的不可名状存在

### 古神注视

- 存在超越一切的古老存在（古神），通过某些途径注视此世界
- 古神的目光可伪装为"能力"赋予人类，实际是在读取信息

### 帝国登记制度

- 帝国对超凡者有登记/备案制度
- 主动出示技艺后可走备案手续
- 未备案前建议保密

- **内城/贵族**：子爵等贵族，名义统治者，实际权力有限（受教会和守夜人牵制）

- **底层**：码头工人、贫民区居民。最容易被诡异侵蚀和教会渗透的群体
