# 从这里开始

这个文件夹只做三件事：用 Codex 里的小说插件协作写作、保存多本小说项目、保留一份干净的工作流母版。

## 写一本新书

1. 打开 `小说项目/新书模板_复制后改名`，复制一份并改成书名。
2. 直接在新书文件夹里填写 `辅助文档/00_使用说明与当前状态.md`，再按需要填写大纲、人物和设定。
3. 在 Codex 中打开“写小说真的太简单了”插件后，直接告诉 Codex 当前项目文件夹和你要做的事。例如：

   `当前项目是 小说项目/巨鹿死局。先读当前状态和第 2 章细纲，再帮我检查这章还缺什么。`

4. 正文和改稿直接写入 `正文/`；同章重写覆盖原文件。台账只在作者采用当前稿后更新。

## 同时写多本书

每本书各用一个目录，例如：

```text
小说项目/
  巨鹿死局/
  新书A/
  新书B/
  00_项目索引.md
  新书模板_复制后改名/
```

切换书时，只需在对话中说明当前项目是哪一个。不要让两本书共用同一份人物、时间线或伏笔文件。

## 带到另一台电脑

复制整个 `小说写作插件与工作流` 文件夹。新电脑需要在 Codex 中安装或启用本地的 `插件源码/` 插件；小说项目始终保存在 `小说项目/`，不放进插件源码。

没有插件时，项目文件仍能直接编辑；安装插件后，再让 Codex 读取当前项目并使用网关、去 AI 味或质检能力。
