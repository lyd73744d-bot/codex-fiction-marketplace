# 写作协作工作流

这个目录是小说项目的长期工作台，不是另一套写作软件。

- `插件`：统一的项目、台账、正文、审稿、账号和模型工作台。
- `Codex协作技能`：由 Codex 执行的研究、构思、写作、审稿和去 AI 味规则。
- `网关`：只处理账号登录、模型目录、模型调用和余额；不保存小说正文。
- `项目`：每一部小说的项目目录。台账是唯一事实来源，候选想法留在 working 区。
- `集成`：AINovel、InkOS 与授权资料能力的接入说明，均由 Codex 选择调用。
- `字字珠玑式细纲台账模板`：新书可直接复制的项目骨架，包含当前章细纲、写后回执、人物/时间/伏笔台账和审稿记录。

## 日常使用

1. 在 `项目` 下打开或登记一本小说。
2. 在插件的 Codex 总控里给出目标。
3. Codex 读取项目、必要时检索公开资料，并自行选择网关中的模型；作者指定模型时，按指定模型调用。
4. 结果先作为候选；作者确认后才写入正文和创作台账。

模型调用见 [模型调度.md](模型调度.md)。

## 新书模板

复制 `字字珠玑式细纲台账模板` 到小说项目根目录后开始填写。它以“已确认正文为准、当前章细纲、写后回填”为主，不要求每章使用固定的钩子、爽点或六步结构。模板说明见 [字字珠玑式细纲台账模板/README.md](字字珠玑式细纲台账模板/README.md)。

网关密钥、服务器密码和模型供应商凭据只放在服务器环境变量中，不写入本目录、项目文件或插件包。
