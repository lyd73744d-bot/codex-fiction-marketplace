# 写作协作工作流

这个目录只说明本地小说项目怎样与 Codex 协作，不提供另一套网页工作台。

- `Codex Skill`：负责新手引导、研究、脑洞、工程建档、伏笔、必要的自然章节笔记、模型调度和候选验收。
- `外部写作模型`：作者当次同意后负责正文初稿、改写、润色和去 AI 味。
- `网关`：只处理账号登录、模型目录、模型调用和余额；不保存小说正文。
- `项目`：每部小说一个本地目录；`辅助文档/00-08` 是唯一台账，候选稿只放 `Codex候选/`。
- `MCP`：负责网关和候选文件，不负责建书、维护台账或写正式正文。

## 日常使用

1. 把新书文件夹或现有小说文件夹告诉 Codex。
2. Codex 读取项目、必要时检索公开资料，并给出一个主推荐模型；作者可以改选。
3. 需要付费模型时，MCP 调用模型并把完整结果写入 `Codex候选/`。
4. 结果先作为候选；作者确认后才写入正文和创作台账。

模型调用见 [模型调度.md](模型调度.md)。

## 新书模板

Codex 直接复制插件内置 `project-template`。新手不需要手工填空；Codex 一步一步提问并维护文件。

网关密钥、服务器密码和模型供应商凭据只放在服务器环境变量中，不写入本目录、项目文件或插件包。
