# 辅助文档放置与使用

## 放在哪里

每一本小说都在自己的项目根目录建立 `辅助文档`。例如：

`C:\Users\86186\Desktop\番茄写作项目\你的书名\辅助文档`

不要放进插件源码，也不要把不同小说共用同一份人物、时间线和伏笔台账。

## 桌面目录里的两份资料

- `辅助文档_通用底座`：旧工作流的通用资料与写作规则，适合拿来搭新项目。
- `辅助文档_卢象升项目当前版`：当前《巨鹿死局：卢象升召来两千骑砍精锐》的实际副本，只供查看和备份；正式修改仍在小说项目本身进行。
- `字字珠玑式细纲台账模板`：当前推荐的新书模板。复制整套目录到新小说项目根目录，按实际进度填写。

## 新书先建立什么

1. `00_使用说明与当前状态.md`：写到哪一章、下一步做什么、哪些事情已经发生。
2. `01_全书大纲.md`：全书方向、分卷安排、已经确认的长期安排。
3. `02_人物台账.md`：人物身份、已知信息、关系和当前状态。
4. `03_世界观与设定.md`：系统、力量、时代和硬规则。
5. `04_时间线.md`：日期、地点、事件先后与伤势、资源变化。
6. `05_伏笔管理.md`：埋下、回收、不能提前透露的内容。
7. `06_风格与写作要求.md`：文风、叙事距离、禁写表达和章节习惯。
8. 需要时再加人物防 OOC、战场规则、参考书迁移规则和已写正文反推资料。

也可以直接从 `字字珠玑式细纲台账模板` 开始：它已经带有上述文件，以及 `细纲/01_当前章细纲.md` 的自然段细纲说明。细纲只处理当前章；正文采用后再回填台账，未采用的新稿不写成事实。

## 日常顺序

脑洞时先看当前状态、大纲和相关设定；细纲前补人物和时间线；正文完成后只回填真正发生变化的事项。要用模型时，Codex 通过插件绑定这些文件；要问下一步，直接说“我现在该做什么”。
