# 模型调用（融合版）

1. fiction_list_models：看可用模型与余额
2. fiction_recommend_models：按任务给责编建议
3. 作者可指定 modelIds 覆盖建议
4. 每次先询问作者；当次选择使用后才以 authorConfirmed=true 调用 fiction_generate_to_file。长文传 background=true，等待时做本地只读连续性准备，再用 fiction_generation_status 取回正文结果
5. 把推荐结果的 modelIds 传给 fiction_generate_to_file；fallbackChain 只传 true/false
6. 作者从自己已有的其他模型带回内容时，用 fiction_write_artifact + modelId 落盘；带 chapterNo 时直接写入正文。事实台账只在作者采用当前稿后更新
