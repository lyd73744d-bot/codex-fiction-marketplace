# 模型调用（融合版）

1. fiction_list_models：看可用模型与余额
2. fiction_recommend_models：按任务给责编建议
3. 作者可指定 modelIds 覆盖建议
4. 每次先询问作者；当次选择使用后才以 authorConfirmed=true 调用 fiction_generate_to_file（完整生成→txt→记录到审稿记录/模型写作记录.md→再读）
5. 把推荐结果的 modelIds 传给 fiction_generate_to_file；fallbackChain 只传 true/false
6. 作者从自己已有的其他模型带回内容时，用 fiction_write_artifact + modelId 落盘；未确认候选只记过程，不进入故事事实台账
